This page doubles as the library's browser test suite and as a small, interactive tour of WebSharper.UI. Every example below is built with the same reactive primitives that the tests exercise against a real DOM.

Runtime templates

Dataflow stress test

A Var updated every animation frame measures the cost of pushing changes through views.

Test suite

QUnit runs the F# suite against the real DOM. The tests cover variables, views, list models, serialization, elements, input controls, reactive attributes and runtime templates.
